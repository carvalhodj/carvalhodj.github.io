{%- comment %} Sends visitors to the page in their language before anything renders. A language picked with the header flag (retro:lang) wins. Otherwise the visitor's country is guessed, first from the time zone (Brazil only), then from the browser language's region, and matched against `regions` in `languages`; everyone else gets the default language. It only redirects when the page has a translation (an hreflang link above), and never for crawlers, so search engines index every language. On the 404 page (`not_found: true`) the missing address decides first: /pt/anything gets the Portuguese 404. The host serves one 404 for every missing URL, so the address travels along as ?path= and is put back. {% endcomment %} {%- assign auto_language = true %} {%- if site.retro.auto_language == false %}{% assign auto_language = false %}{% endif %} {%- if site.languages.size > 1 %}{% if auto_language or page.not_found %} {%- assign default_lang = site.lang | default: "en" %} {%- endif %}{% endif %}
